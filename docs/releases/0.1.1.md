# JV Desktop 0.1.1

JV Desktop 0.1.1 fixes Linux release asset/checksum filename compatibility.
Application functionality is unchanged from 0.1.0. Requires JV CLI 0.4.9+ on Linux.

Published packages now use canonical filenames without spaces:

- `JV-Desktop_0.1.1_amd64.deb`
- `JV-Desktop-0.1.1-1.x86_64.rpm`
- `JV-Desktop_0.1.1_amd64.AppImage`

`SHA256SUMS` and `BUILD-INFO.json` refer to those exact names. The release workflow
checks filenames before publication and verifies fresh downloads afterward.
Prefer v0.1.1 for verified downloads: GitHub renamed v0.1.0 package filenames,
leaving its checksum listing inconsistent. v0.1.0 remains unchanged.

No new application features, credential handling or production acceptance.
Windows native JV execution, bridge images and guaranteed remote cancellation
remain unsupported.
