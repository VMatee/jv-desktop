# JV Desktop 0.2.3 — release candidate in preparation

- Select Structured sessions with a compatible JV CLI to let the coding agent
  inspect PNG, JPEG and WebP files, then continue editing and testing the project.
- A failed agent turn is reported separately from a disconnected CLI bridge.
  Unsupported Structured services show their support code without automatically
  resubmitting the task in Legacy mode. Reopen the folder and explicitly select
  Legacy when that service requires it.

Candidate pairing: JV CLI 0.5.3 and JV Desktop 0.2.3. Install CLI first, then
Desktop. Windows requires AMD64 Windows 10/11 and WebView2. Trusted-host mode
continues to give tools full account filesystem/network access without approval
prompts; use a dedicated worker account. Chat image attachments are not included.

Windows installers are unsigned. Verify the installer against its pre-release
SHA256SUMS before running it. These notes do not announce an available release:
installer acceptance and publication are pending. Linux integration and the
final cross-platform release remain pending.
