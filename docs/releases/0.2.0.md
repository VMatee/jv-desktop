# JV Desktop 0.2.0

JV Desktop now supports native Windows 10/11 AMD64, alongside Linux x86_64.
Install JV CLI 0.4.9 or newer separately; Desktop does not bundle, install or
update the CLI.

## Highlights

- Native Windows JV CLI discovery and protocol-1 bridge integration.
- Native workspace folder selection, including spaces and Thai paths.
- Windows Job Object ownership and bounded cleanup of the Desktop-owned tree.
- Windows trusted-host status and fixed permissions for dedicated worker PCs.
- Existing Linux permissions and execution behavior retained.

## Windows

Download `JV-Desktop_0.2.0_x64-setup.exe`. Installation is per user and does not
require Administrator privileges. WebView2 is required; the installer can obtain
the public Microsoft runtime if missing. JV CLI should normally be installed at
`%LOCALAPPDATA%\Programs\JV CLI\jvcli.exe`.

Native Windows launches `jvcli.exe bridge --stdio --execution-mode trusted-host`.
Model tools have full filesystem access, network access and no approval prompts,
with the normal privileges of the account running Desktop. Use an ordinary
dedicated Windows account. Windows Firewall remains enabled. This is unrestricted
tool execution, not Windows sandbox isolation. Network-denied Windows execution
is unsupported by the pinned restricted-token backend.

The installer is **unsigned**. Windows may show SmartScreen or publisher warnings.
SHA-256 verifies bytes but does not establish publisher identity.

## Linux

AppImage, DEB and RPM remain available. Read only, workspace write with tool
network, and workspace write without tool network retain their existing behavior.
Linux continues to launch `jvcli bridge --stdio` without trusted-host arguments.

## Privacy and limitations

Passwords remain memory-only and prompts use private stdin protocol channels.
Desktop state is separate from terminal CLI state. Normal uninstall preserves
user data, projects and the separately installed CLI; the Windows uninstaller's
optional remove-data checkbox is an explicit separate choice.

Stop cancels local work; remote job state may remain unknown. No WSL, ARM64,
macOS, auto-update, integrated terminal, PTY/ConPTY, bridge images or guaranteed
remote cancellation is included.

`SHA256SUMS` and `BUILD-INFO.json` cover the exact Windows and Linux release
assets from one source commit. See the README for installation instructions.
