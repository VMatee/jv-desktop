# JV Desktop 0.1.0

First Linux x86_64 desktop release. Requires separately installed **JV CLI 0.4.9+**.

- JV CLI bridge protocol 1 integration with memory-only sign-in.
- Native project-folder picker and explicit workspace/tool-network permissions.
- Chat, structured command activity, changed-file feed and Thai/Unicode input.
- IME-aware Enter, Shift+Enter and Stop with conservative local cancellation.
- Debian, RPM and AppImage packages with SHA256 checksums.
- Offline demo for trying the interface without an account or service calls.

Local Stop does not guarantee remote job cancellation. Windows native JV execution,
bridge images, Desktop resume and integrated terminals are not included.

Install/uninstall instructions are in README. Existing JV CLI is not bundled,
updated or removed by Desktop. Packages are unsigned. Linux live acceptance passed
before release preparation; release validation uses offline/local checks only.
