# JV Desktop 0.2.1

- Windows now requires the official JV CLI 0.5.0 release or newer. Older CLI versions are rejected during detection and bridge startup.
- Missing/outdated CLI messages show the Windows version requirement and official download location.
- Windows installation instructions now start with the separately installed [JV CLI Windows x86_64 installer](https://github.com/VMatee/jv-cli/releases/tag/v0.5.0).
- Linux retains JV CLI 0.4.9 or newer and its existing permission modes.

Install CLI first, then Desktop. Windows supports 10/11 AMD64 with WebView2 and
uses explicit trusted-host execution: full tool filesystem access, network allowed,
no tool approval prompts and the normal privileges of the dedicated Windows account.
Use an ordinary account and keep Windows Firewall enabled. Trusted-host is not
sandboxed; restricted Windows network denial remains unsupported.

Desktop does not bundle, install or update JV CLI. Stop is local; remote job state
may remain unknown. The per-user Windows installer is unsigned and may display
SmartScreen/publisher warnings. Verify SHA256SUMS; hashes identify bytes, not the
publisher. No WSL, ARM64, auto-update or terminal/PTY/ConPTY is included.
